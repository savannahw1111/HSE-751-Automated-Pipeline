# HSE-751-Automated-Pipeline


### Purpose

This notebook runs through an in-depth, automated pipeline for uploading, examining, exploring, and analyzing data in preparation for a final machine learning model step. It is intended to be highly reproducible. The tested dataset is accessible in the repository. The notebook has explanatory Markdown cells before each major section and three additional modifications to improve the pipeline.

### Instructions

Download the data file, or any other file, from the repository and open the Google Colab notebook. Upload the data file into the Dropbox option under the "Upload Data" section. Run through the entire notebook and use the outputs for a fully informed analytical pipeline.

### Assumptions and Limitations

This automated pipeline is best suited for the dataset provided. It is not suited for unstructured data, automatic standardization, cleaning, or preprocessing. It is also designed to provide a limited number of visualizations and relationship comparisons. The two machine learning models, logistic regression and decision trees, are the only current models, as this pipeline is not suited for deep learning or boosting models. If you decide to use another application such as VS Code or Jupyter, please be aware that the results may vary. The dataset and notebook must be in the same directory.
